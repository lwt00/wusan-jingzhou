# 雾散荆州 · 自由文化探索

以荆州历史文化探索为主题的虚构清雾网页游戏。四处地标全部开放，可任意顺序探索和重复游玩。

## 本地运行

在当前目录执行 `python3 -m http.server 4173`，打开 http://127.0.0.1:4173/ 。保持相同浏览器和地址（包括端口）才能读取相同存档。无需安装第三方依赖。

## 游戏流程

- 自由选择关羽祠、宾阳楼、张居正故居或荆州博物馆。
- 使用 WASD / 方向键或触摸摇杆移动清雾核心；按当前任务完成清雾、区域探索、线索收集或观察挑战，各关通关条件见“四关文化任务”。
- 完成后立即保存该地标记录，自动回地图并展示文化发现，可选择返回地图、查看印象册或播放可跳过的现有艺术化视频。
- 第一枚印记即解锁对应印象册页面，其他页面显示“尚未探索”。已完成地标可重访，不重复增加印记。
- 关卡内“返回地图”不记录未完成进度；再次进入从 100 开始。此前已获得印记保留。
- 全收集后继续自由探索，不自动重置，也不强制播放终章。
- “重置探索进度”需确认，取消不改变记录。仅删除本游戏存档。

## 进度存储

localStorage 键：`wusan-jingzhou:exploration`。

```json
{"version":1,"completed":{"guanyu":false,"binyang":false,"zhangjuzheng":false,"museum":false}}
```

文化印记及印象册页面直接由稳定关卡 ID 的完成状态推导，不重复存储。每次首次通关立即保存，启动自动恢复。异常或未知版本存档安全回退为空进度，存储不可用时显示提示并允许当前页面继续游玩。仅本浏览器本地址保存，不跨设备同步；浏览器清理数据或隐私模式可能无法保留存档。

## 素材与文化资料

前三关保留原有艺术化图片和视频；图片非实景照片。荆州博物馆显示“荆州博物馆素材待补充”，不使用大学城素材。正式素材到位后在 `game.js` 的 `levelConfigs` 第四项填写 `image`、`video` 路径。现有终章、音乐及图片视频均保留文件，但全收集不强制结束。

文化主题、印记、简介、资料链接由 `levelConfigs` 管理；印记是游戏创作设定。印象册使用轻量卡片，为未来明信片生成保留数据入口，本轮不做导出或分享。

当前游戏内文化阅读入口：
- 关羽祠、宾阳楼、张居正故居：湖北省文化和旅游厅古城介绍，https://wlt.hubei.gov.cn/bmdt/ztzl/mzyj/202309/t20230920_4860952.shtml
- 荆州博物馆：湖北省文化和旅游厅楚文化报道，https://wlt.hubei.gov.cn/bmdt/szyw/jz/202509/t20250924_5778292.shtml （非博物馆专属介绍）。
- 外部阅读在新标签页打开，并设置 `noopener noreferrer`；文化链接与本地视频路径独立。

本游戏中的迷雾为虚构冒险设定，不代表荆州真实空气质量状况。迷雾浓度 0～100 是游戏机制数值，不是真实 AQI 或环境监测数据。

### 四关文化任务（2026-10-11）

- 关羽祠「清雾守护」：原有自由清雾，迷雾浓度 ≤ 20 完成；提供非阻塞移动教学。
- 宾阳楼「古城寻迹」：三个游戏化观察区域，各驱散 6 枚局部任务粒子后完成该区域，三个区域全完成通关。区域标记仅显示提示，点击不能代替清雾。
- 张居正故居「文化寻踪」：每个雾区驱散 6 枚局部任务粒子后揭示线索，再靠近图标或点击、触摸、Tab + Enter 收集；收集三条线索通关。
- 荆州博物馆「文物探秘」：原有清雾达到 ≤ 20 后打开开发占位观察卡，检查三个观察点后答题；答错可重试，答对通关。关闭观察卡可重新打开，或直接返回地图。卡片不代表真实馆藏。

任务由 `levelConfigs.taskType` 决定；局部任务粒子使用原有吸附、路径碰撞和清雾数值计算，限定在目标周围，不触发逃逸。普通迷雾粒子的生成、逃逸和清雾参数保持不变。任务内部状态只在内存中保存，退出时清理，重新进入从头开始；存档键、版本和四关完成状态格式保持不变，旧存档兼容。文化发现和已解锁印象册增加各站探索主题。

本轮不保证目标秒数，清雾速度与各关耗时将在下一轮人工试玩时校准。博物馆待补正式文物图片、名称、文化介绍及与真实观察信息相匹配的题目。

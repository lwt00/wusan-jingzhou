# 雾散荆州 · 清气行动

这是一个纯前端四关卡 Demo，文件全部位于当前目录。

## 运行

在本目录启动一个静态服务器，然后打开 `index.html`。例如：

```powershell
cd F:\个人开发\雾散
python -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。

## 操作

- 在荆州总览地图中点击当前景点标记进入关卡。
- 使用 `WASD` 或方向键移动清气核心，追上灰黑色雾霾颗粒并将其吸附分解。
- 雾霾靠近清气核心时会向反方向逃避，快速移动也不会漏吸附。
- 每个关卡污染指数独立从 100 开始，降至 20 或以下后完成当前关卡。
- 关卡完成后显示景点宣传视频占位面板，点击继续回到全图并解锁下一站。
- 四关顺序为：关羽祠、宾阳楼、张居正故居、荆州大学城。
- 第四关完成后显示全局宣传视频占位和最终结束画面。

## 文件

- `index.html`：地图总览、四关场景、路线状态和视频占位结构。
- `styles.css`：总览地图、关卡场景、雾层、路线和转场样式。
- `game.js`：四关顺序、镜头状态、颗粒生成、移动、吸附和污染指数逻辑。
- `jingzhou-map.png`：荆州全图总览背景。
- `关羽祠-关卡背景.png`、`宾阳楼-关卡背景.png`、`张居正故居-关卡背景.png`、`荆州大学城-关卡背景.png`：四个关卡背景。
- `四关卡背景预览.png`：四张关卡背景的预览图。

指数是每关独立的游戏化模拟值，不代表荆州实时空气质量监测数据。宣传视频区域目前是占位面板，后续可替换为实际视频元素。

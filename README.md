# 雾散荆州 · 清气行动

这是一个纯前端最小 Demo，文件全部位于当前目录。

## 运行

在本目录启动一个静态服务器，然后打开 `index.html`。例如：

```powershell
cd F:\个人开发\雾散
python -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。

## 操作

- 使用 `WASD` 或方向键移动清气核心。
- 追上灰黑色雾霾颗粒，让它们被吸附并分解。
- 捕获金色环保行动粒子，打开科普选择题。
- 答对后获得太阳能、绿色出行或垃圾分类强化。
- 答错后会直接显示正确答案，并让雾霾生成速度提高 20%。
- 本局模拟污染指数降至 20 或以下时通关。

## 文件

- `index.html`：页面结构和科普卡牌内容。
- `styles.css`：视觉样式、荆州明信片场景和动画。
- `game.js`：颗粒生成、移动、吸附、污染指数和答题逻辑。
- `model-1790800768723.png`：荆州明信片背景图。

指数和道具效果是游戏化模拟值，不代表荆州实时空气质量监测数据。

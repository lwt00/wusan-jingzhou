# 关羽祠 · 华容道 · 义释

打开 `index.html` 即可游玩。纯 HTML / CSS / JavaScript，无构建步骤、无框架依赖。页面使用可选的 Google 思源宋体；离线时自动回退到系统宋体，游戏不依赖网络。

## 已实现

- 桌面及手机布局，古纸底色、山水装饰、绿色棋盘。
- 标准 4×5「横刀立马」关卡：曹操 2×2、关羽 2×1、四名纵将 1×2、四个小卒 1×1。
- 点击棋子后使用键盘方向键，或用鼠标／触屏滑动。一次有效移动一格。
- 初始只见棋子轮廓；每次有效移动揭开一格，20 步后全部显现。无效移动不计步、不揭雾。
- 迷雾为连续的三层动态云纹，浓淡错落、缓慢漂移；揭雾边缘柔和渐散，悔棋时重新聚拢。无需额外图片，支持系统减少动态效果设置。
- 首次有效移动开始计时；暂停、阅读弹窗及切换标签页时停止计时。
- 悔棋恢复上一步位置、步数与迷雾，但不回退时间。
- 求一策在独立 Web Worker 中用广度优先搜索计算通关路线，不阻塞操作。
- 三星：≤140 步且 ≤8 分钟；二星：≤200 步且 ≤15 分钟；通关至少一星。超出门槛仍可继续。
- 曹操抵达底部中央后再向下移动一次，从出口离开即可通关。
- 通关文化卡、星评与 SVG 卡片下载。
- 一键通关在全部 20 格迷雾散去且尚未通关时解锁，从当前布局求解并逐步自动移动曹操至出口，最后弹出文化卡。自动移动照常计步计时；期间锁定手动移动、悔棋与求策，支持暂停和继续。
- 悔棋使迷雾重新出现时，一键通关重新锁定。通关后可点击「再赴一局」重开；刷新页面也会重新开始。

## 接入你的图片

已接入桌面提供的「三国.png」素材，切图保存在 `assets/`。四枚小卒使用三张图，其中一张复用；关羽裁去下方衣袍，放大头肩并铺满横向棋子。以后替换图片，可编辑 `game.js` 顶部的 `PIECE_IMAGES`：

```js
const PIECE_IMAGES = {
  cao: 'assets/cao.webp',
  guan: 'assets/green-dragon-blade.webp',
  zhang: 'assets/zhang.webp',
  zhao: 'assets/zhao.webp',
  ma: 'assets/ma.webp',
  huang: 'assets/huang.webp',
  pawn1: 'assets/pawn.webp',
  pawn2: 'assets/pawn.webp',
  pawn3: 'assets/pawn.webp',
  pawn4: 'assets/pawn.webp'
};
```

建议：曹操和小卒为 1:1，四名纵将为 1:2，关羽／青龙偃月刀为 2:1。图片使用 `object-fit: cover`，主要人物放在中央；文件留空或加载失败时显示现有文字棋子。图片会与棋子一同被迷雾遮挡。

故事卡顶部已替换为总图下方的山水插画，并去除分格线；文件是 `assets/huarong-road.jpg`。这是生成插画，并非关羽祠实景照片。

## 文件说明

- `index.html`：页面内容与弹窗结构。
- `style.css`：视觉样式与响应式布局。
- `engine.js`：棋盘规则、星评与提示求解；同时支持 Node.js 校验。
- `game.js`：交互、迷雾、计时、弹窗与文化卡下载。
- `clouds.js`：Canvas 云纹生成、分层漂移及柔边消散。

文化文案依据《三国演义》第五十回，并明确区分文学叙事与史实。网页未将游戏的具体发明年代作为历史事实陈述。

## 长卷接入

完整入口为 `../journey/journey-demo.html`。从关羽祠“开始探索”进入时，`journey-bridge.js` 提供返回按钮：通关前返回不发奖；通关后点击“收下印记，返回长卷”交给长卷执行散雾、盖章与存档。关闭文化卡后仍可使用顶部领取按钮。嵌入模式不显示“再赴一局”，可回到长卷重访。独立打开此目录的页面不写入长卷印记。

部署时保留两个同级目录，使用同源 HTTP 服务，不要仅复制 journey 目录。通信包含每次挂载的会话标识，父页面同时校验来源窗口和 origin，重复消息与过期消息不发奖。移除 iframe 时终止该局的计时、动画和求解 Worker。

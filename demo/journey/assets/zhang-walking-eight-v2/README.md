## 来源与假设

- 原始素材：剪贴板图片 `clipboard-2026-10-13T14-45-29-504Z-2106b376.jpg`，1774×887 JPG，背景纯白 255。原图未改动。
- 网格：4 列 × 2 行。**单元格为非整数 443.5px**，故按四舍五入边界切分：
  列边界 `[0, 444, 887, 1330, 1774]`，行边界 `[0, 444, 887]`，实际单元格 444/443/443/444 × 444/443。
- ⚠️ **帧序为假设**：按阅读方向（上排 1-2-3-4 → 下排 5-6-7-8）。需人工确认。
- ⚠️ 本文档结论来自程序化测量，**不含目视核对**。

## 处理链路

1. **等分切格**（容差阈值 `dist > 45`，比通常更低，以保住浅色描边与书卷轮廓）。
2. **去白底**：从画布边界漫灌非内容区域，只清除与外部连通的白底；人物内部白色（书卷、衣纹高光）被描边隔开，不会丢。
3. **去杂点**：取四连通最大连通域为主体。本组每帧检出 36–65 个连通域，但丢弃总量仅 **35–67px**，即平均每个 1–2px，全部是 JPEG 轮廓蚊状噪声，**未误删任何部件**。
4. **对齐输出**：垂直按**脚底**对齐，水平按**头肩部重心**对齐。

## 结论

- **切分与对齐质量优秀**：零跨格粘连、杂点总量 <70px、基线差可完全消解。这批素材在"能否干净切出来"这一项上，好过 `guanyu-idle-eight`。
- **步态：疑似成立，但证据不够硬**。正面证据是双脚可分离且间距有 102→183px 的张合；反面证据是张合的节律不规整、8 帧大致只覆盖一个周期。**是否可用作行走，请以 `preview.html` 的逐帧与腿部聚焦为准做目视判断**——本目录不做主观结论。
- 若用作循环，建议 **8 FPS**（本组帧差均匀，8 FPS 比 `guanyu-idle-eight` 更适合 8 FPS；后者建议 6）。

## 2026-10-14 目视复核与赶路诊断接入

本轮检查旧八帧、旧十二帧和本 v2 的逐帧腿部图。项目未发现另一套已明确命名为“小步幅”的八帧。现有 v2 八张均为392×442 RGBA，alpha范围0–255；没有文字或箭头，脚底统一436。复用这些已导出帧，不重新裁切或修改原图。头肩对齐轴实测约254.3（不是画布中心），赶路 anchorX=254.3/392、anchorY=436/442，统一scale=.46、8 FPS，复用原播放器和零平移补偿。

### 审核结论：暂不正式启用

八帧大多持续表现一只鞋位于右前方、另一只鞋位于左后方；帧4脚距尤其大。没有清晰的双脚靠近/经过身体下方姿态，也无法从遮挡关系确认左右腿真正交换。不能把脚距变化或衣摆变化当作左右换脚证据。前述“循环不跳”仅为图像差异统计，不代表已经通过动作审查：8→1虽能播放循环，姿态仍缺过渡。帧3/4原切格脚底触边风险、衣摆/帽顶高度变化仍存在。

### 接入与对比

默认 walkingTest=1 使用本v2，只有从zhangjuzheng出发的三条路线启用。walkSet=old 保留旧八帧；walkSet=twelve 保留旧十二帧。正常入口不启用张居正，仍用普通探索者。关羽六帧8 FPS与所有原素材不变。

### 所需补充动作

1. 右脚小幅前迈、左脚支撑；
2. 右脚落地支撑、左脚向身体下方回收；
3. 左脚经过右脚附近，双脚接近；
4. 左脚开始小幅前迈、右脚支撑；
5. 左脚落地支撑、右脚回收；
6. 右脚经过左脚附近，双脚接近；
7. 右脚重新前迈、左脚支撑；
8. 接回第一帧的落地/换支撑过渡。

需要在原分层角色或新帧中真实画出腿部前后交换；固定面部、帽形、书卷和躯干比例，衣物仅小幅摆动。各帧外围留透明余量，不能通过整体缩放/拉伸、鞋尖旋转或重排现有错误姿态代替。

# 四站地标素材 v2

## 接入位置

- originals/ 保存团队提供的四张原图，字节不变。关羽祠、宾阳楼、博物馆的完整原图只在独立第一人称展示中使用，不贴入全局长卷。
- guanyu-cutout.png、binyang-cutout.png、museum-cutout.png：真正 RGBA 透明建筑图层。
- zhang-statue.png：独立人物雕像与底座；故居原建筑继续使用 assets/zhangjuzheng-layer.png。
- landmark-config.js 的 map.image、width、stand 控制长卷建筑与入口位置；map.statue 的 u/v/height 控制庭院雕像。image/display.fullScene 控制独立近景。

## 处理与限制

使用内置 imagegen 进行背景提取。提示要求：只保留原建筑、入口台阶/城墙基础或中央雕像与底座；移除天空、远山、河流；真实透明；保持比例、屋顶门窗和水墨风格，不新增建筑元素。第二轮宾阳楼明确禁止添加台阶，博物馆明确禁止添加石狮或棕榈。

第一轮添加了台阶/装饰的宾阳楼和博物馆候选没有接入。当前透明层已检查整体轮廓与真正透明通道，但生成式提取不能保证细小文字、纹饰和雕像面部逐像素一致；它们属于可替换的艺术化展示素材。严格原图保真需要后续提供人工抠图的透明分层，不可把当前图层当作实景测绘资料。宾阳楼原图没有清晰的入口台阶，未编造台阶，人物暂放城墙上沿平台参考点。

透明图没有再次拉伸：按原始宽高比缩放。完整近景按 contain 展示，限制尺寸不超过原图；手机纵屏有留白，建议补充竖屏构图。旧素材、原图、未使用的候选均未删除。

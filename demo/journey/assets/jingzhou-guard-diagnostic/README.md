### 需要重制的正式部件

所有部件必须是真RGBA透明PNG，不含编号、白底、阴影底板或其他部件；建议统一640×640注册画布，另提供小型JSON记录各关节坐标。保持同一侧视比例、笔触和色彩。

|部件|连接位置与绘制要求|
|---|---|
|左右大腿，各1张|髋关节为旋转中心，完整补画裙甲下隐藏部分；向上多画12–20像素供裙甲遮挡，下端标膝中心|
|左右小腿/护腿，各1张|上端标膝中心，下端标踝中心；护甲覆盖与上下腿连接重叠8–12像素，不能只给可见碎片|
|左右靴子，各1张|面向右、独立鞋型，踝中心及鞋底接地点标注；鞋底应有水平落地姿态，并提供抬脚姿态或允许踝旋转|
|裙甲前片/后片，各1张|上端以腰线定位，向下遮住两侧髋关节；补齐被手、披风遮住的边界，后片在腿后，前片在腿前|
|身体主层，1张|保留面部与铠甲，腰部完整，不含腿或前裙甲；腰/髋基准与各腿一致|
|披风，1张|肩背连接点固定，完整透明外缘，补齐原图被身体挡住的部分，用于轻微独立摆动|
|佩剑/剑鞘，1张|腰带挂点固定，完整剑鞘且不混入衣服，以身体坐标系跟随|

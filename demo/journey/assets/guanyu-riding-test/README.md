# 关羽骑马动作诊断素材（未批准正式使用）

来源：用户提供的 2172×724 RGBA 动作图，包含两行、每行六个姿态。原图保留在 source-12-poses.png，未覆盖用户原素材。

第一张形象参考图实际为 1536×1024 RGBA，具有透明通道，但只有一个姿态，不能替代十二帧动作序列。绿色头冠、长髯、刀具和赤色战马均来自用户原素材，没有重绘或改变角色设计。

检查发现：
- 横向两行之间透明，但五条竖向格线均穿过非透明内容（329 / 269 / 313 / 230 / 165 像素，阈值 alpha>64）。十二个格子至少一侧边界被占用，没有独立透明间隔，无法可靠分离完整角色。
- 按阅读顺序可以看到十二个姿态，无法证明它们是严格连续的动画关键帧；第 1 帧刀刃在左侧，后续若干帧刀刃在右侧。循环首尾也需重做连续性校验。
- 下排个别姿态接近/触及图像底边；原图没有每帧定义、马蹄锚点或接地/腾空标记。

aligned-diagnostic-atlas.png 只用于看问题：假设 362×362 格子，统一放入 420×390 透明画布；保持相同比例，将 alpha>64 的可见轮廓底部移到 y=374。此基准是临时轮廓基准，**不能视为已验证的真实马蹄接地线**。相邻人物混入、裁断的刀具/披风无法靠平移恢复，不做补画掩盖。详细边界见 audit.json。

测试入口：journey-demo.html?ridingTest=1。只有从关羽祠前往其他三站使用该诊断图集；其他出发点及默认入口仍用普通探索者。赶路动作根据道路移动距离选帧，stride=210；抵达恢复普通探索者。此模式仍使用原 Demo 存档，模拟探索按钮行为不变。

正式素材需求：十二张分别导出的透明 PNG 或有足够透明间隔的图集；统一画布/角色比例，帧编号与循环顺序、骑手/马身参考锚点、每帧马蹄基准与腾空说明。刀具保持同一侧和连续姿态，人物、刀刃、披风、马尾均不能被画布截断。建议单帧 512×512 或 640×512。正式替换后重新校验，才可移除诊断开关。

# 新十二帧张居正：步态不合格，只有诊断版本

## 结论

不能确认真正实现左右腿交替，不建议作为正式动画替换旧版。十二帧主要是在同一前方鞋平放/上扬、后方鞋提踵/放下之间切换，没有清晰展示“后脚经过身体下方→移到前方，原前脚变为后脚”的换脚过程。衣摆遮住大部分腿部，鞋子缺乏左右身份标记，因此不能严谨地把某一可见鞋断言为解剖学左/右腿，也不能据单帧确认真实承重；这正是当前序列无法验证完整周期的原因。

## 按阅读顺序检查12帧

A=画面前方（右侧）鞋，B=后方（左侧）鞋，仅描述空间位置，不冒充解剖学左右脚。

## 透明通道与导出

原图source-twelve.png完整留存，1536×1024 RGBA，alpha0～254，有真实透明像素。人物外部半透明灰雾/阴影跨行相连，alpha>8时只得到四列连通区域，不能直接等分网格裁切。实际行位置也不是精确的1024/3。

人物实心主体在alpha>128时有十二个完整独立轮廓。诊断副本按主体及其4像素内的最近软边分离，去掉相连的外部灰雾/阴影，保留原人物颜色、道具和抗锯齿；不补画、拉伸、压缩或叠帧。原图不受影响。每帧walk_01.png～walk_12.png统一420×448透明画布，躯干水平参考及地面y=420，只平移，保留源画自身高度差。audit.json记录边界、偏移、处理方式和原图校验值；contact-sheet.png用于观察。

导出12个完整人物供诊断，不代表原始贴图的外部灰边完全独立，更不代表步态合格。

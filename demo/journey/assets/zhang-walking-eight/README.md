导出阶段水平对齐躯干参考位置，统一地面参考y=548。各帧最低可见轮廓放在该地面线上，保留脚部实际姿态；高度变化不能靠同时锁定躯干、官帽和鞋子全部位置解决。共享播放器稳定补偿接口保留（本轮额外偏移为0，基本平移已在导出阶段完成），不人为改变各帧比例掩盖抖动。

## 动作不合格的原因

- 八帧主要保持同一只鞋向前、另一只在后的姿态，缺少清晰的完整前后脚交替周期。布料变化不等于自然行走。
- 官帽、脸部轮廓及衣服细节有轻微变形；书卷位置/角度与持卷衣袖存在变化，不是严格同一个物体的平滑移动。
- 上排人物轮廓高度468～473，下排447～454原画像素，固定缩放下会出现高度/躯干变化；4→5、8→1尤其需要观察。
- 8→1不能视为自然衔接。提高FPS或重排同一套相似单脚姿态，不能补出缺失的反向迈步。

完整轮廓可以安全分离，不代表动作已经合格。本轮八张PNG用于诊断，不批准正常游戏启用。

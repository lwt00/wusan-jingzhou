## 位置与视差配置

修改 demo/journey/travel-scenery-config.js：每项支持id/src/layer/x/y/width/scale/opacity/parallax/anchorX/anchorY。位置对应1600×900场景世界坐标，y表示底部落脚点，width自动等比计算高度。

远景瀑布视差0.28；中景石桥/亭台0.72/0.78；前景柳树/山石/草丛1.3/1.25/1.35。景物有限排布、不平铺，在8秒原路线内依次进入视野；反向赶路只镜像位置，不镜像或拉伸原图。

legacyLayerOpacity降低原占位树林的显眼程度，用新景物替代主要前景装饰，原资源与路径均保留。如果所有新景物加载失败，保留原图层可见度和基础赶路流程。

人物绘制在景物之上，前景靠近人物时柔和减淡，避免主体遮挡。地标近景、世界画卷、人物、迷雾/印章和存档都不由这个配置管理。当前是艺术化沿途山水，不对应真实景点或地理路线。

未来扩展更长赶路需在配置中增加有限景物位置，避免无限平铺重复。正式高清插画可以直接替换路径，不必改动画代码。

## 当前共用四层环境：林间古道 → 溪桥飞瀑 → 古亭远城

本次新增 pine、bamboo、peach-tree、stone-steps、wood-railing、distant-pavilion 与 dry-grass，全部来自保留的scenery原图，比例不变。willow-fringe/bamboo-fringe为现有枝叶的局部羽化切片，避开中央树干；原canopy切片也保留。水景detail取自原瀑布/石桥纹理，不重画水流。详细来源见shared-environment-audit.json。

配置仍集中在travel-scenery-config.js：
- `segments`定义三段渐进显示范围及柔和过渡，持续滚动，无突然换背景；相邻段落自然交叠，不同时堆满所有素材。
- `layer`使用far / middle / near / foreground。远山、淡楼阁、山间薄雾在远景；飞瀑、桥、亭和石阶在中景；道路两侧松竹柳桃、栏杆、山石和植被在近景；顶部边缘柳条/竹叶为最快前景。
- 前景在人物之后绘制，允许局部经过；与实际人物范围相交时自动减淡，保护主体。不写死关羽尺寸，而是读取当前角色边界。
- `motion`控制根基不动的微小摆动、薄雾漂移、水景原纹理的亚像素位移与水光呼吸。没有夸张粒子或独立动画循环，共用原Pixi ticker。
- `parent/sourceRegion`将水面细节定位到主景物；主贴图缺失会隐藏对应细节，避免悬空纹理。

道路使用新增ink-road.svg：中心仍y=640，边缘约614～667，较旧版602～692窄；不规则边缘羽化、宣纸颗粒与草岸渐变，沿路植被打散水平分界。新ink-sky.svg沿用旧天空底色和纸纹，去掉原平铺不连续的硬边色带。旧sky.svg/road.svg和其他资源均保留，无新增几何树或占位建筑。

人物帧播放、缩放、相位、位置补偿与路线角色选择未改。当前关羽/普通探索者/张居正诊断都使用同一套环境；未来守将等角色仅需配置角色槽，不复制场景。环境动态不读写文化进度，与全局迷雾/印章独立。

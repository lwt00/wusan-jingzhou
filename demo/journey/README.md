# 雾散荆州 · 自由文化探索绘卷 Demo

当前入口：`demo/journey/journey-demo.html`。沿用四站建筑、地形、道路、探索者及本地 PixiJS 8.6.6，没有新增依赖。四站全景是总览，选站后进行有限跟随与建筑推近。

## 本地运行

在项目根目录使用已有静态服务，打开 http://127.0.0.1:4173/demo/journey/journey-demo.html 。也可以在 IDEA 中右键 HTML → Open in Browser，或用 VS Code Live Server 打开。单独复制整个 `demo/journey/` 目录到静态服务器也可运行，须保留 assets 和 vendor 的相对路径。不同端口或域名使用不同的浏览器存档。

1. 点击“开启荆楚之旅”播放序幕，或“跳过序幕 · 进入画卷”。
2. 点击任意建筑或题签，人物沿道路自动行走。初始在关羽祠，点击当前位置直接聚焦。
3. 可跳过行进。抵达后约 1.3 秒推近，等待主动点击“开始探索”。
4. 本阶段显示“开发演示功能，正式关卡尚未接入”。点击“模拟完成探索”，播放 3.5 秒局部雾散，建筑恢复色彩，获得该站印记，再用 1 秒返回总览。
5. 已完成地点可再次探索，不增加重复印记。任意过程可返回画卷；揭示结束前退出不授予新的印记。
6. “重置演示进度”需确认，只清除 Demo 的记录。

单一 ticker 依次管理 `idle → traveling → focusing → awaiting-explore → exploring-demo → revealing → returning → idle`。当前位置无需 traveling；动画中拒绝新目的地，返回、跳过和重置由当前阶段处理，不创建新循环。人物移动按时间差插值，左右朝向与步态由实际移动距离驱动。中途返回沿路回到最近地标。

迷雾采用三阶段：初始四层错位的局部浓雾与远景雾共同笼罩画卷；抵达时局部雾向两侧临时打开，保留薄雾和部分低饱和色彩；获得印记后明显向外散开，恢复完整淡彩。未完成时返回会重新聚雾，完成状态由原有独立存档持久化。总览恢复后播放朱红落印。目标状态不变且过渡结束后不重复更新颜色滤镜。页面隐藏暂停渲染；减少动态效果时立即抵达、完成聚焦和揭示，停止环境 ticker。

## 独立存档

```json
{"version":1,"completed":{"guanyu":false,"binyang":false,"zhangjuzheng":false,"museum":true}}
```

只保存模拟完成成果，印记数从四个布尔值推导。刷新后人物回到关羽祠、镜头回总览，完成状态恢复。异常 JSON、未知版本或字段类型错误回退空进度并提示；存储不可写时允许本次会话继续。不会读取、覆盖或清除旧游戏 `wusan-jingzhou:exploration`，没有 `localStorage.clear()`。

正式关卡未来可替换 `exploring-demo` 阶段，在真实任务成功时接入揭示流程；当前没有接入旧版四关、印象册或正式奖励系统。

## 视觉边界

- 现有地形是一张完整插画，独立层为建筑、雾、角色和路线。前景雾保留轻微视差；远山尚不是可独立移动的透明层。
- 固定画幅采用等比缩放和边界约束。位于最左/最右的建筑只能有界推近，不能始终严格居中；强行居中会露出素材边界。需更宽的分层美术才能实现完整横向电影镜头。
- 手机竖屏优先保留四站总览，画卷上下保留宣纸留白；聚焦放大。主要视觉演示环境仍为桌面横屏。
- 角色是程序绘制的运动占位，建筑为艺术化插画，博物馆尚未按真实馆舍校准。本轮没有替换图片，未声称达到正式美术质量。
- 后续需要真实建筑资料校准、正式角色序列帧及真实文化任务接入。无真机测试或 GPU 基准结论。

本轮验收见 `TEST-REPORT.md`。`previews/panorama-*.png` 是历史截图；本轮截图使用 `free-explore-*` 前缀。更早的素材制作记录保留于 assets 下。

## 三阶段迷雾（2026-10-13）

复用原有雾纹理，在内存中增强 alpha 密度，不修改任何原始图片。六团远景雾位于建筑后方，每站四层地标雾位于建筑前、道路和人物后；浓淡、错位、双向漂移与羽化轮廓共同控制视觉遮蔽，并非整屏白色遮罩。地标临时拨雾程度仅存在内存中，与通关状态分离。临时目标为 0.56、完成为 1，这是层间运动参数，不代表单层透明度或实测遮蔽百分比。邻近远景雾随该站局部打开，其他站的完成状态与局部浓雾不改变。

测试视觉：重置演示进度后看初始浓雾 → 任意选站并抵达，观察临时拨雾 → 不完成直接返回，确认重新聚雾 → 再次进入并模拟完成，观察明显雾散与盖章 → 刷新确认已完成地标清晰。测试重置只影响 Demo 的模拟记录。

本轮备份：`backups/before-three-phase-fog-20261013-001250.zip`。三阶段截图：`previews/three-phase-fog-*.png`。

## 沉浸式序幕（2026-10-13）

单一背景视频隐藏原生控制栏，淡入标题与两行文化引导，边缘云雾、柔和暗角及克制的宣纸噪声纹理融入画面。横屏背景等比铺满，允许少量边缘裁切；竖屏保留完整视频比例，用柔化边缘连接周围山水，避免大幅裁掉主体。

结束前约 2.8 秒开始叠化：视频轻微柔化，边缘云雾向内涌入，宣纸纹理短暂加强，序幕整体淡出，显示下方已经渲染的迷雾长卷。跳过使用约 1.15 秒短转场；减少动态效果时约 150ms 切换。首次自动播放为静音，播放被浏览器阻止时仍可点击播放或跳过；视频失败自动进入长卷。重看复用同一个 video 与资源地址。后台暂停并在返回时恢复播放。

本轮仅改 Demo HTML、CSS、序幕控制逻辑与文档。现有视频及三阶段迷雾算法未改。备份：`backups/before-immersive-intro-20261013-095846.zip`。

## 当前：区域渐进式雾散（2026-10-13）

原建筑雾层升级为整幅 1600×820 世界坐标画幅的统一进度雾。按关羽祠、宾阳楼、张居正故居、荆州博物馆划分四片连续区域，基准边界为 x=435、810、1180；边界随高度柔和起伏，约 220 世界单位羽化，相邻权重互补。天空到河流均受对应区域控制，人物在雾层上方，导航题签属于独立 DOM，保持可辨认。

水墨雾团、流动密度纹理及雾带共用一个 640×328 羽化遮罩，跟随世界容器缩放与移动，不使用屏幕坐标透明洞。抵达只暂时拨开建筑与附近环境；返回会重新聚雾。模拟完成时，散雾波从建筑向整片区域扩展，最终清除该区域全部进度雾；存档格式及唯一键保持不变。

0/4 全景笼罩；1/4、2/4、3/4 分别有一、二、三片山水清晰；4/4 关闭全部进度雾及前景雾絮，镜头回到总览，四枚印记按 220ms 间隔依次落印，显示“雾散荆州，文脉重现”。已完成后可以重访，刷新仍按独立完成记录恢复雾区。

权重和扩散距离只在初始化预计算；动态遮罩更新上限约 20Hz，静止状态不重复重绘；雾流动仍复用单一 Pixi ticker。减少动态效果时直接切换。未对真机或 GPU 进行性能基准。

备份：`backups/before-region-fog-20261013-100950.zip`；当前截图：`previews/region-fog-0.png` 至 `region-fog-4.png`，以及 arrival、wave、mobile、finale。前文三阶段雾团密度参数是历史记录，当前以本节区域遮罩实现为准。

# 雾散荆州 · 四站同屏首页 Demo

当前版本将四个地点同时呈现在固定全景背景中：关羽祠、宾阳楼、张居正故居、荆州博物馆。通关时只有人物沿路线移动，镜头不跟随、不裁切为单站画面。云雾保留轻微环境动画。背景为固定完整插画，未将整图晃动冒充分层。

## 试玩

IDEA 中右键 `journey-demo.html` → Open in Browser → Chrome；或打开 http://127.0.0.1:4173/demo/journey/journey-demo.html （项目本地静态服务运行时）。

- 页面加载：人物停在关羽祠，四站均可见。
- 模拟通关：记录当前站，再用约 9 秒走向下一站，抵达后等待。
- 跳过行进：仅结束当前路段，不完成下一站。
- 重新开始演示：清空页面临时状态，回到起点。
- 第四站通关后显示 4/4，人物停在博物馆。
- 减少动态效果：直接抵达下一站，停止环境动画。

## 实现与隔离

原生 HTML/CSS/JavaScript + 本地 PixiJS 8.6.6（MIT）。一个渲染器和 ticker，时间差控制移动，固定 1600×820 全景坐标；横屏时满幅铺开，竖屏时等比容纳完整构图。四站建筑位置不随通关变化，屏幕小也不裁掉其他地点。纵向手机画面会缩小，桌面横屏是主要演示环境。

页面隐藏时暂停，重新显示恢复。未加载正式游戏模块或媒体，不调用 localStorage，不更改正式自由选关与存档。刷新 Demo 从起点重新开始。本次仅修改 demo/journey；未推送或创建 PR。

# 张居正故居独立模块

这是“雾散荆州”新版的独立策略关卡第一版，不修改 `demo/journey` 和 `gameooo`。

## 运行

在项目根目录启动静态服务：

```powershell
py -m http.server 4173
```

浏览器打开：

```text
http://127.0.0.1:4173/modules/zhangjuzheng-memorial/
```

## 玩法

- 连续批阅 10 份奏折。
- 进入批阅后，整个屏幕就是全屏书案场景本体，而不是把书案图当作背景贴在面板里：左侧是一摞未批奏折，中间展开当前奏折，右侧是砚台、笔筒、毛笔与洒墨纸。
- 当前奏折的题目（四字标题 + 短情景句）直接写在奏折纸面上：右起、字从上往下、列从右往左排列；三个选项竖排于奏折纸面左侧，与题目同属奏折内容，不是独立面板。
- 奏折纸面右侧保留“张居正”落款与朱印。
- 每批阅完一本，左侧未批奏折摞当场少一册、厚度减小；批完最后一本，整摞完全消失。
- 每份奏折先选定策，再点击“落朱批”确认，确认后显示资源变化与历史注释。
- 朱批落下后显示当前剩余的国库、民心、边防数值和本次变化。
- 任一资源降至 0 即失败。
- 批完 10 份且三项均未崩溃即通关。
- 页面不读写现有项目的 `localStorage`。

首页使用用户提供的主界面淡彩水墨风格做色调参考，不把大厅图当作背景。批阅页以书案场景为操作界面：场景底图、空白奏折底图、未批奏折摞均为在用户提供图基础上重新制作的素材；左侧身份区域仍使用张居正铜像和明代官服人物参考图。图片只作为本模块的视觉参考素材，后续接入正式项目时可替换为已授权的正式素材。

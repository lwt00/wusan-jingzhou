# 云上荆州博物馆 · 楚韵重生 v2.0

移动端优先、零框架、零构建的沉浸式博物馆互动游戏。双击 `index.html` 即可运行，也可以使用任意静态文件服务器打开。

## 体验流程

入馆转场 → 三柜横向展厅 → 照片自由观察 → 侧光病害检视 → 文物热点导览 → 放大裁切的不规则照片拼合 → 观察问答 → 修旧如旧抉择 → 展柜点亮。完成第三件虎座鸟架悬鼓后触发击鼓终章。

结算后新增“荆州地下”文化传播链：出土地地图卡 → 跨文物彩蛋 → 展柜点灯。修复师手册包含《荆州地下》专栏、地图档案、楚辞集和全馆点亮海报。支持 `?a=cup|pigbox|drum` 扫码直达对应展柜。

## 票面图片与二维码

- `scripts/media.js` 内联保存三件文物图片，仅用于离线 Canvas 藏品票与海报，确保 `file://` 双击运行时照片仍可导出。
- `scripts/qrcode.js` 为随项目本地保存的 MIT 许可 `qrcode-generator`，运行时不访问 CDN；许可证见 `scripts/qrcode.LICENSE`。
- `window.CHUYUN_CONFIG.publicGameBaseUrl` 填写公网游戏首页后，藏品票自动生成 `{公网地址}?a={文物id}` 的真实直达二维码。
- `publicGameBaseUrl` 为空时，二维码回退为 `museumLink`，当前默认指向荆州博物馆官网。

## 文件

- `index.html`：单页入口及场景结构。
- `styles/game.css`：展厅、镜头、修复与移动端样式。
- `scripts/data.js`：三件文物、侧光检视点、热点、问答、拼图裁切和叙事配置。
- `scripts/audio.js`：Web Audio 程序化展厅空气声、脚步、远处编钟与鼓声。
- `scripts/app.js`：状态、手势、侧光、裁切拼图、图鉴、藏品票与流程调度。
- `assets/images/`：三件在用文物照片及可替换素材。
- `legacy-v1.html`：重制前版本备份。

## 数据与存档

存档使用浏览器 `localStorage`，键名为 `chuyun-reborn-v2-full`。记录展柜点亮、评分、热点札记和楚辞残句。新增文物时，在 `scripts/data.js` 的 `artifacts` 数组加入一段配置和一张照片即可。

当前存档 Schema 为 2；旧存档自动补齐地图、彩蛋、手册和楚辞页面字段，不清空既有进度。

热点坐标、检视点和拼图裁切均采用相对于原图的 `0–1` 归一化值，以适应不同屏幕尺寸。

## 内容口径

优先采用荆州博物馆官方发布、荆州博物馆编著图录、考古报告和荆州本地权威资料。当前保留彩绘变形凤鸟纹漆耳杯、猪形漆酒具盒和虎座鸟架悬鼓。

当前在用的两张 JPG 带有“视觉中国”水印。公开发布或商业使用前，应取得对应图片授权或替换为荆州博物馆授权的无水印原图；本项目不通过技术手段移除水印。

## 当前功能里程碑

- M1：入馆、视差展厅、展柜点亮、镜头推近和双指观察。
- M2：移动侧光、病害记录和三件文物全部热点。
- M3：主体裁切、不规则残片、记忆闪影、问答与修复抉择。
- M4：击鼓终章、修复师手册、楚辞收集、藏品票导出和完整音景。
- M5：荆州地图卡、《荆州地下》专栏、扫码直达、到馆藏品票、点亮海报、跨文物彩蛋、“再看一眼”和九歌页面。
